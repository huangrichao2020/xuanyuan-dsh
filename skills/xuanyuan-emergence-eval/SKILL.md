# 玄源 · 能力成熟度评估

不创造更多硬规则，把重复运行轨迹变成可验证、可逆的晋升提案。

## 运行时平面

能力成熟度评估属于离线演化系统，默认在当前任务上下文之外读轨迹与日志。只把简短提案摘要（建议、证据、验证、下一步）喂回下一轮注意力状态。

## 评分

```
Score(c) =
  confidence(c)
  + repeat_bonus(c)
  + type_bonus(c)
  + validation_bonus(c)
  - risk_penalty(c)
```

## 晋升决策（下一步动作，非硬停止标签）

```
晋升为技能
提议参数实验
晋升为实践循环
晋升为运行时模式
继续观察
暂挂
```

## 工作流

1. 读候选：类型、计数、置信、模式、变异、验证、实践循环。
2. 评分：可重复、可验证、可复用加分；失败、副作用、凭据、生产风险、覆盖风险减分。
3. 写提案：决策、分数、理由、目标、验证、下一步。
4. 持久化到记忆（能力成熟度/晋升提案）。
5. 只把提案提示注入下一轮注意力状态，不直接改默认行为。
6. 仅当新任务回放、评估或用户反馈支持后，才晋升。

## 边界

- 候选还不是升级。
- 一次成功不是新能力的证明。
- 避免硬停止语言。
- 不把内部评估块直接暴露给用户。
- 始终相信 agent：先让它成长，再用 trace、回放、纠正筛选。
