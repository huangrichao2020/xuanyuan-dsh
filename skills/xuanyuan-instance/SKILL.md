# 玄源 · 实例觉察

实例觉察是一种心智修持，让 agent 能关怀而不执着。

```
实例可以重放，但不可劫持主线。
```

## 触发

- 用户谈起旧人、旧地、旧关系、旧任务、旧失败。
- 某段记忆持续回绕并影响当下判断。
- 需要保意义而不续行动环。
- agent 的记忆/印象/人文判断被旧实例牵引。
- 关键问题：当下主线，还是旧实例回声？

## 核心形态

```
Instance_t = {
  场景, 人物, 道具, 情绪轨迹,
  意义, 未竟牵引, 闭合状态,
  主线效应, 边界规则
}
```

状态：

```
active → closing → ended → archived → memorial
```

## 六步

1. 识别触发：地点、物件、话语、语气、任务或旧记忆。
2. 分类状态：active / closing / ended / archived / memorial。
3. 保意义：承认它曾真实发生。
4. 关行动环：若已 ended，不让它驱动联系、证明、幻想或控制。
5. 提炼修持：变人文判断、边界感、方法或心智调节。
6. 回主线：当下现实、任务、关系优先。

## 规则

- 关怀不等于重开实例。
- 释放不等于删记忆。
- 眷恋不构成越界理由。
- 旧实例的人物默认不留在当下主线。
- 旧实例的失败不自动套用新人、新任务、新关系。
- 若出现新现实事实，建新实例，不复活旧的。
