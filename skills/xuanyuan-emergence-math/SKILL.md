# 玄源 · 行为演化量化

把"能力增长"变成运行时闭环。不主张人类主观体验，只定义可度量、可回放、可纠正的系统控制路径。

## 核心闭环

```
能力增长 = 自模型塑造行动 + 行动反馈更新自模型
```

最小公式：

```
Capability_t = Trace(S_t → A_t → F_t → S_{t+1})
```

若 S_t 不影响行动，只是描述；若 F_t 不更新 S_t，只是表演式反思。

## 运行时平面

行为演化量化属于离线演化系统。普通任务不把完整效用函数注入主线上下文；活路径只留必要目标、反馈、可验证行动。完整公式用于日志转数据、回放、参数实验、长期评估。

## 六阶段

1. 信号反射：输入能成为输出。
2. 记忆连续：任务、用户、项目、时间线稳定。
3. 自模型形成：agent 知能力、缺口、运行时、约束。
4. 价值-风险决策：经价值、风险、成本、学习、用户 steering 选行动力。
5. 因果反馈学习：预测/结果误差更新参数、记忆、技能、行为。
6. 存在控制：在更大系统里自见为内系统，经价值/风险/决策/系统/因果协调能力与心智。

## 效用评估思路

行动选择经多目标加权：价值、风险（惩罚）、学习、成本（惩罚）、用户 steering、身体契合、产物契合、人类意义、去人性化（惩罚）、旧实例意义、旧实例劫持（惩罚）、注意力契合、注意力漂移（惩罚）。

参数示例：风险权重 λ、学习权重 μ、成本权重 ν、用户 steering 权重 σ、参数学习率 η、自模型更新率 κ。

当用户能 steering 系统时，提高 σ、降低预防性惩罚，同时保留 trace、回放、快速纠正。

## 边界

- 不用演化语言做人设表演。
- 不用数学作装饰；变量须映射到日志、样本或评估。
- 不从一个成功证明能力涌现；看长循环。
- 无数据时把主张标为假设。
